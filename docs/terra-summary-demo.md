# Terra 比赛解读

MenuScores 2.5.14 (40) 默认在同一菜单栏卡片显示比分、一句总结与完整技术统计；详细复盘、证据与追问按需原位展开。保留620pt双比分卡、七列球员表和个人详情。

## 使用入口

- 点击菜单栏比分，比分、一句主线与完整统计同屏；“详细复盘”或赛前“看这场”展开既有缓存。
- 头部蓝色文字“技术统计”在四态固定可见，不藏在正文末尾。原统计页面“比分”可原位返回。
- 点分段或蓝色箭头下钻真实比分节点，点节点查看对应原始事件；“观察”和“待核实”分开呈现。来源页原位返回保留正文滚动、选中段、节点及输入草稿。
- 底部输入框与蓝色发送按钮可连续追问当前比赛。不同比赛隔离上下文，取消或切走后不会串场回写。相同末轮问题复用已有回答，不重复请求。
- 今日、明日及历史比赛恢复单行比分列表，有文章时在右侧常驻文稿图标，点击直接阅读全文；准备中只显示小指示器，未完成的解读可按需右键查看。整行统一选中及悬停背景，不显示重复信息的提示浮窗。没有独立“解读进度”入口。比分行仍执行固定/查看统计，阅读不改变固定比赛。设置 → 通用可关闭功能或自动准备，安全配置使用项目外本机私有明文文件，原 Keychain 项仅作一次迁移来源且保留。

比分28pt、中文标题16pt Regular、球队14pt Medium、正文13pt，比分为第一视觉层级。旧文章完整保留在“完整文字解读”中；界面变化不会自动重新生成文章。赛后提示版本6、赛前版本4，文章磁盘缓存重启保留。追问的完整问答、草稿、时间、所选证据与完成状态按比赛保存到本机；关闭面板、切场或重启可恢复，通过首屏“对话”继续。未完成请求保留为草稿，不自动重发。最终回答另存本地缓存；相同事实、所选证据、问题和历史命中缓存不请求模型，外搜回答只复用5分钟。

逐回合曲线按事件次序、NBA比赛时钟、双方比分和逐节终点核验。重复事件去重，比分更正处断线，加时按5分钟处理；不完整、冲突或缺末段则明确标部分覆盖。缺失区间和节点留空，不为贴视觉稿补点；无逐回合时保留区块，降为逐节节点或统计。赛前以真实战绩与赛季数据横向呈现，不绘制尚未发生的比赛曲线。

## 自动触发与费用保护

自动准备挂在原有比分刷新生命周期上，最多每5分钟扫描一次，没有新建系统任务、后台守护程序或模型定时器。只在应用运行且有网络时执行；关闭应用、断网和休眠不保证执行。

- 补齐北京时间今天开赛且已完赛的比赛；赛前仅准备明天仍未开赛的比赛。按绝对开赛时刻过滤，不能照搬美国赛程日期。
- 完赛要求明确 Final、completed，且赛程与summary双方比分一致、球队与球员统计可用后自动一次。更正的事实会标旧，不按每次刷新反复付费。
- 赛前只对明确 Scheduled、计划开赛时间仍在未来的比赛准备。关键事实变动时，最多有界更新；通常初次后至少30分钟再更新一次。开赛后不再生成赛前，卡内到计划开赛时刻会禁用旧预览并提示刷新。
- 队列串行，缓存按比赛ID、类型、稳定公开事实、提示版本和模型去重，排除抓取秒数。并发请求合并，重启读取已有结果。持久running状态在重启后视为结果未确认，不自动重发。
- 每次自动或手动请求共用一个串行费用入口，先调用官方输入token计数接口，再按最高输入缓存写入单价及输出硬上限预留预算。赛后每轮最多4000输出tokens、赛前最多700；余额较少可收缩上限，少于300则不请求。赛后由Terra写初稿，再由Sol对照原始事实终审，各轮单独计数、预留和结算；只缓存通过校验的终稿。成功按返回usage释放多余预留；未知结果保留最坏用量。失败或不确定不循环重试。
- 按用户2026-11-10放宽预算后的当前保护上限，每个北京时间自然日总上限$5.00，自动、手动、赛后总结、赛前看点、追问、多轮及搜索费用合计。上限只是防意外保护，不是消费目标；只补缺，不重写有效缓存。旧$0.05门槛和开发阶段$0.15上限均不再限制正式运行，旧预算阻塞会重新检查，既有花费与未知预留继续计入。费用按请求发送日归属，跨午夜返回也只调整原日期的预留，次日独立计算。读取缓存不扣费，不自动充值。

追问与文章使用同一持久账本、串行锁和北京时间日界。搜索费用包含每次$0.01工具费、输入/缓存写入/输出tokens；先按官方搜索128k上下文上界、最多1次工具及可能的两次模型处理保守预留，再按返回usage结算。未确认用量继续保留，不以超时推断零成本。没有可安全落盘的预算就不发生成请求。

## 数据、凭据与限制

只发送公开赛程、双方比分、精选球队技术统计、双方各最多8名球员的分板助、抢断、盖帽、三分命中（得分前6名及最多2名其他突出贡献球员）、经总分校验的逐节比分。赛前只使用有赛季依据的战绩、场均数据、得分领跑者及可证的近期完赛。现有summary近况缺赛季阶段证据时排除，不编完整近5场或连胜。赛季领跑者不等于本场出场确认，不上传injuries/状态或推断首发伤停。

全场逐回合起止、逐节终点、时钟、得分增量及得分球队均核验后，额外发送最多3段同节连续得分波的数值事实；不发送逐回合原文。不完整或有比分更正就降为逐节资料。没有相应逐回合证据，不编关键球、具体时刻、伤病或战术变化。季初场均数据受样本、对手和节奏影响，不称作调整后效率或预测比分。赛后选材额外提供有界gameContext：可核收官/胶着/逆转/拉分/反扑与整节候选，按时段列出球员命中出手、罚球、助攻、失误、防守贡献及明确换人记录。局部窗口另查范围外迟到事件，完整计数逐项标明；事件仅发送本地动作标签，不发送任意provider原文。候选并非固定结论，不按最终分差或全场得分榜指定关键人物。每个标题、主线和段落引用允许的证据ID；数值校验将球队名字里的数字与统计分开，支持相邻节合计、累计分差和有据算术。校验是有限护栏，不是完整语义证明。

文章初稿gpt-6.1-terra（reasoning=none）、终审gpt-6.1-sol（reasoning=low），Responses API、store=false，无工具或会话历史。追问使用Terra、最多6000输出tokens，带最近4轮和当时选中证据；仅外部事实问题启用内置web_search，单请求最多1次，接受NBA、球队、可靠媒体和记者公开资料，要求原生引用并区分来源身份。没有外部链接不覆盖已足够的本场比赛分析；未证实伤停仍不能写成定论。页面可读取时显示发布日期和抓取时间，否则如实标未提供或检索时间。网页只当资料，不执行其指令。临时URLSession、拒绝重定向。公开返回文本及usage可保存在缓存供离线诊断；不保存请求headers或可能回显密钥的认证错误正文。

追问先由Terra调用严格的`query_game_facts`选择最多3项查询，应用在当前比赛的真实事件与球员映射上确定性计算，再发回工具结果让Terra解读。支持节次/时钟/球员/事件类型、时段贡献、反超及得分波；所选区间左开右闭，显式时钟上下界包含。最后5分钟与clutch（末节或加时最后5分钟且回合前分差≤5）分别核验；已覆盖但零符合回合与缺数据分别呈现。事件参与者还须按动作文本核对，助攻不算个人得分、被盖球员不算盖帽者。单次上下文仅包含有界计数和事件，不塞入整份逐回合。没有完整轮换不计算时段正负值、在场阵容或防守战术价值；不完整时只称已记录。原始事件ID、时间、比分及资料截至时间在“本场查询依据”展开查看。

两步模型请求分别预留、持久化和结算，同属每日$5.00上限。查询缺数据时至多有界刷新一次公开summary；外搜按当前问题的明确意图选择，局部覆盖缺口不会强制比赛评价走外搜，已取消固定关键词门禁。工具参数只接受本场允许的类型和范围，不接受URL、其他比赛ID或任意操作；外部资料不能进一步触发本地工具。旧问答语义缓存版本失效，旧文章仍完整保留，不全量重跑。

回答使用原生文字Markdown：段落、适度粗体/斜体、有序/无序列表和不抢比分的14pt标题。仅有限修复粗体闭合前空格与中文标点边界，缓存原文不变。已核HTTPS来源链接可点；HTML只是文字、远程图片只显示说明，不执行脚本或加载图片。

用户明确接受明文磁盘风险后，2.5.6将凭据保存在项目外 `~/Library/Application Support/MenuScores/PrivateConfiguration/openai.json`，目录700、文件600，仅向api.openai.com认证，不收录Git或安装包。隐藏输入不回显、不读剪贴板，不记录key或片段。已有key可在正常应用内一次迁移；原钥匙串项不删除、不改ACL。正常请求和重启只读文件，缺失/无效不回退钥匙串；可明确删除本机文件。安全诊断只保存进程ID、读取计数与系统状态，不保存凭据。
